# Security

## Reporting a problem

Please do **not** open a public issue for security problems. Report them privately:
[Security → Report a vulnerability](https://github.com/Andys-3D-World/cnc-craft/security/advisories/new).

Examples: a file (SVG, DXF, project, library, language pack …) that can run code or read files, text from a board or
the network that ends up as HTML, leaked Wi-Fi passwords, updates that are not checked properly.

You will get an answer within a few days. Fixes go into the next release and are listed under **Security** in the
[CHANGELOG](CHANGELOG.md).

## Machine safety

CNC Craft controls real machines. If the machine moved unexpectedly, did not stop, or the laser / spindle stayed on,
please open a [bug report](https://github.com/Andys-3D-World/cnc-craft/issues/new?template=bug_report.yml) and choose
**Safety** – these are fixed first. The stop buttons in the software never replace a real hardware emergency stop.

## Supported versions

Only the [latest release](https://github.com/Andys-3D-World/cnc-craft/releases/latest) gets fixes. Update from inside
the app: ⓘ → "Update now".
